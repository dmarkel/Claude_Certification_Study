The Project Plan, Through the 4D Framework

This site is a "learning in public" meta-project: it teaches the certification material while modeling the AI Fluency Framework (Delegation, Description, Discernment, Diligence) that Course 1 itself teaches. Below is how this project's own major tasks were divided between human and AI — and why.

Vision & Success Criteria

  • Pass the Claude Certified Architect – Foundations exam.
  • Be able to explain the 4D Framework and generative-AI fundamentals from memory, without notes.
  • Have a diagnostic practice-test system that shows which domain to restudy, not just a pass/fail score.
  • Return to this plan at each stage of the course to deliberately practice Description, Delegation, Discernment, and Diligence — not run them on autopilot.

Task Breakdown by Driver

TaskBest driven byWhy
Research exam scope, syllabus, module structure AI, human confirms Web research and synthesis is fast for AI; the human spot-checks accuracy against what's actually seen in Skilljar.
Site engineering (render engine, quiz/scoring logic, progress tracking) AI, human reviews Deterministic, boilerplate-heavy code is a good delegation target; the human verifies correct behavior in the browser.
Writing the actual study-guide content per module Human, AI assists structure The crux of this whole project: if AI writes the notes from course material, the retention benefit disappears. The human processes and summarizes what they actually learned; AI organizes it into clean, consistent prose.
Drafting practice questions Collaborative The human identifies what's genuinely worth testing; AI drafts question variants and distractors and tags them by domain; the human verifies no invented facts slipped in.
Visual/UX design direction Human (taste), AI (implementation) The human picks the direction and constraints (Bold & Editorial, no gamification); AI builds it.
Fact-checking AI-assisted content Human AI can confidently state incorrect specifics about Claude/Anthropic products — this is the highest-stakes Discernment checkpoint in the whole project.
QA / testing the site (links, rendering, scoring) Collaborative AI runs mechanical verification (unit tests, browser checks); the human does a final pass.
Deployment, ongoing maintenance AI, human approves Git/GitHub Pages operations are low-risk to delegate; publishing still needs a human go-ahead each time.
Repeating the pattern for each new course Collaborative loop The human brings raw understanding from the course just completed; AI structures it fast; the human verifies. This loop is the 4D Framework in practice.

Scope & Roadmap

The full certification path bundles 7 prep courses. This first build covers the reusable system — site architecture, this project plan, and the study/practice-test engine — fully populated for Course 1 (AI Fluency: Framework & Foundations), the course in progress when this site was built. The other 6 courses ship as visible placeholder stubs on the course map: the full path is real and visible, but no content is fabricated for courses not yet studied. Each placeholder gets converted into real content — study guide, knowledge checks, and a domain-tagged practice test — using this same collaborative loop as each course is actually completed.

Courses that map to the official Claude Certified Architect – Foundations (CCAR-F) exam blueprint — Building with the Claude API, Claude Code in Action, and Introduction to MCP — will tag their practice questions with the 5 official exam domains (Agentic Architecture & Orchestration, Tool Design & MCP Integration, Claude Code Configuration & Workflows, Prompt Engineering & Structured Output, Context Management & Reliability) rather than the 4D Framework, so their diagnostics mirror the real exam's own score report. Once enough of those courses are built out, a cumulative 60-question practice exam will pull from all of them, matching the real exam's 4-of-6-scenario, 120-minute, 720/1000-passing-score structure.

Question Rotation & the Course 1 Final Exam

Every question bank on this site — knowledge checks and practice tests alike — is larger than what any single attempt shows you: modules draw 3 of 6 knowledge checks per visit, and the Practice Test draws 3 questions per domain (15 total) from a 45-question pool. Retaking either surfaces different questions, so review actually exercises recall instead of memorized answer positions.

Course 1 also has a Final Exam, reachable from its course page: a longer, comprehensive test (30 questions, 6 per domain, drawn from the same rotating pool) meant to feel like a real sitting — one pass, a full domain breakdown at the end, no reruns needed to see every domain represented. It's scoped to Course 1's own 4D Framework content, not the official CCAR-F blueprint (that cumulative, blueprint-scored exam is the item in the Scope & Roadmap above, still to come as later courses are built out). Practice Test and Final Exam scores are tracked independently on the course page, so neither attempt overwrites the other.
